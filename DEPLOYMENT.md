# Инструкция по профессиональному деплою TeachFlow (yraq.ai)

Этот проект подготовлен для раздельного деплоя: **Фронтенд на Vercel** и **Бэкенд на Render/Railway**.

## 1. Бэкенд (Сервер) — Render.com
1. Создайте аккаунт на [Render.com](https://render.com/).
2. Подключите ваш GitHub репозиторий.
3. Выберите папку `server` как **Root Directory** (или настройте путь при создании Web Service).
4. **Build Command**: `npm install`
5. **Start Command**: `node index.js`
6. **Добавьте переменные окружения (Environment Variables)**:
   - `PORT`: `3001` (или оставьте пустым, Render назначит сам)
   - `JWT_SECRET`: Любая длинная случайная строка
   - `GEMINI_API_KEY`: Ваш ключ от Google AI
   - `FRONTEND_URL`: Ссылка на ваш фронтенд (получите на шаге 2)
   - `DATABASE_PATH`: `/opt/render/project/src/server/db/teachflow.db` (Для работы SQLite на Render нужно добавить Disk в настройках, иначе данные будут стираться при перезагрузке).

## 2. Фронтенд (Сайт) — Vercel.com
1. Создайте аккаунт на [Vercel.com](https://vercel.com/).
2. Подключите репозиторий.
3. В настройках проекта (Project Settings):
   - **Framework Preset**: Vite
   - **Root Directory**: `./` (корень проекта)
4. **Environment Variables**:
   - `VITE_API_URL`: Ссылка на ваш бэкенд (например, `https://teachflow-api.onrender.com/api`)

---

### Что я подготовил для стабильности:
- ✅ **CORS**: Сервер теперь принимает запросы только с вашего доверенного фронтенда.
- ✅ **API_BASE**: Фронтенд автоматически переключается на рабочий сервер через переменную `VITE_API_URL`.
- ✅ **Безопасность**: Установлен `helmet` для защиты заголовков.
- ✅ **Логирование**: Все действия на сервере записываются для отладки.
- ✅ **SQLite Path**: База данных теперь может храниться в любом месте, что важно для облачных хостингов.

### Важное замечание по базе данных:
SQLite — это файл. Если вы используете бесплатный тариф Render без "Disk", ваши пользователи и данные будут удаляться при каждом обновлении кода. Для **настоящей стабильности** в будущем рекомендуется переключиться на **PostgreSQL** (например, через бесплатный Supabase).
